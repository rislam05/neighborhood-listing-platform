# Neighborhood Listing Platform

A simple and accessible neighborhood property platform built with Next.js. The project provides information about property listings, neighborhood sponsors, and voice-help resources.

## Live Deployment

[View the deployed application](https://neighborhood-listing-platform-fawn.vercel.app)

## Features

- Property listings
- Neighborhood sponsor information
- Voice-help resources
- Accessible HTML structure and clear heading hierarchy

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- Vercel
